## 安装

1. 下载 `肥鱼助手-v36.93.apk` 到手机
2. 点击安装（首次需允许「安装未知应用」）
3. 打开 App → 按顶部「上手清单」授权：① 无障碍 ②（可选）麦克风 ③ 填模型 API Key
4. 想先验本地 OCR：高级设置 → 本地 OCR → 「OCR 引擎自检」

## 本地 OCR（三套引擎，设置里随时切换，全部离线）

| 引擎 | 体积 | 特点 | 许可 |
|---|---|---|---|
| **ML Kit 中文识别**（默认） | 约 13 MB | 快、准、开箱可用 | Google ML Kit Terms |
| **PaddleOCR（ONNX Runtime）** | ORT 17.7 MB + 模型 12.5 MB | 复杂排版 / 竖排更稳，稍慢 | Apache-2.0 |
| **Tesseract（tess-two）** | 约 6.6 MB | 老库，仅作备份 | Apache-2.0 |

三套都完全离线、不花 token；`auto.ocr()` / `auto.clickOcr()` / 动作 `look` 通用。

## 应用内「检查更新」

在「高级设置 → 稳定与保活 → 检查更新」旁的输入框里填：

```
https://raw.githubusercontent.com/<用户名>/<仓库名>/main/version.json
```

点检查更新：比对新版本 → 显示更新说明与大小 → 「下载并安装」→ 自动下载并调起系统安装器。

### version.json 字段

| 字段 | 说明 |
|---|---|
| `version` / `versionCode` | 版本号（应用内优先比 versionCode） |
| `url` / `apk` | 安装包地址（可相对路径，相对 version.json 目录） |
| `notes` | 更新说明，显示在更新弹窗里 |
| `size` / `sha256` | 大小与校验值（进度与完整性判断） |

## 更新记录

### 日志里读出来的三个真问题
```
17:32:52 · 面板[收起成胶囊] size=634x148  →  吸到右边 size=173x117
17:33:03 · 面板[收起成胶囊] pos=0,780 size=470x314 collapsed=true running=true
17:33:03 · 面板[吸到右边]  size=407x165     ← 收起了还是 407x165，一点都不小
17:33:03 全部结束，共操作 1 次              ← 只回放了一步就说"结束"
```

### 1. 任务结束后不是最小样式 → 修好
根因：收起（`applyCollapsed`）只藏了"顶部状态行"和"普通按钮行"，
**没藏"运行态停止行"**（■ 停止 / ⏸ 暂停 / ✎ / 🎤），所以收起后还挂着 407x165 的大条；
而且任务结束时先收起、随后 `applyRunningUi(false)` 又把按钮行弹回来 → 看起来完全没收起。

修法：
- 收起时把**停止行也藏掉**，只留小胶囊
- `applyRunningUi` 现在尊重「已收起」：收起状态下永久只显示胶囊
- **任务跑完 / 你点停止 都会自动收成小胶囊**（`完成后自动收成小胶囊` 默认开，跟老版本一样）

### 2. 「清空运行日志」点了没用 → 修好
根因：按钮只改了界面文字，**服务端日志缓冲区没清**，界面轮询立刻又把旧日志刷回来。
修法：新增 `AaService.clearLogBuffer()` 真清缓冲区，按钮改名为「清空运行日志」并提示「运行日志已清空」。

### 3. 配方回放把任务当"完成" → 修好（这条最坑）
根因：`tryReplayRecipe()` 回放成功后直接 `continue` 到下一轮 → 轮数只有 1 就"全部结束"。
日志里就是「回放 1/1 点「下一题」→ 配方回放完成 → 全部结束，共操作 1 次」，你当然觉得没干活。
修法：
- 回放只是"先试试上次的路"，回放完**继续让模型判断**，绝不当作
